# Data attribution

The real sparse matrices in `data_AmRDR/` are provided with the AmRDR experiment code for reproducibility. The default real-matrix experiments use `cari`, `cage`, `mk9-b1`, `n4c5-b2`, `ch5-5-b2`, `D_8`, and `GL6_D_9`. Please cite the [SuiteSparse Matrix Collection](https://sparse.tamu.edu/) and consult each matrix entry for its original attribution and applicable redistribution terms.
